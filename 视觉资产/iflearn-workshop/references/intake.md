# 活动信息采集（每次生成前必做）

**核心纪律：每一场活动都重新问，不得沿用上一场的时间、地点、名额、报名二维码、署名或"不能提的内容"。**
`references/examples/aigc-video/` 只是**版式参考**（其中的日期、名额、署名都来自某一场活动），不要拿它当默认值。

## 怎么问

一次性把下面的清单发给用户（可整段复制），让用户填空或口述；能确认的项不要替用户"合理猜测"。
用户明确说"你看着办"的项，才用占位并在交付说明里单列。

```
要出这几样：横版海报 + 易拉宝 + 现场横幅 + 微信转发文案。
先确认下面几项，没有的我会留占位、不编：

一、活动本身
1. 系列/期数名（如「AIGC 创作篇」）+ 课程中文标题 + 英文短标题（2–3 个词，要能代表这门课）
2. 讲师姓名与头衔（要不要上海报）
3. 时间：日期 + 星期 + 起止时间（须符合 24 小时制）
4. 地点：校区 / 楼栋 / 教室
5. 形式：线下还是线上？要不要自带电脑？

二、主办与署名
6. 主办方全称；有没有联办单位（有的话给全称和署名顺序）
7. 页头要不要写「主办」两个字？（默认只放 IF.Link Logo，不写字）

三、课程内容
8. 这门课讲什么 / 现场做什么 / 最后带走什么（各一句，越具体越好）
9. 主要工具或技术点（只列确定能用的）
10. 有没有"不能对外提"的内容或工具？（比如还没跑通的部署方案）

四、报名
11. 报名开放时间 / 截止时间
12. 名额上限
13. 报名方式：表单链接、群二维码，还是现场报名？
14. 报名表二维码图片（没有就留占位）
15. 费用说明：是否需自费、是否提供额度

五、素材与交付
16. 主题插画：用现成的图、指定风格，还是我来画？
17. 合作方 / 主办方 Logo 文件
18. 用途：上墙海报、易拉宝、横幅、微信群转发、投影、印刷？（决定给 1x 还是 @2x）
19. 文案语气与禁用词
```

## 回答 → 字段对照

| 用户回答 | content.json 字段 |
| --- | --- |
| 期数名 | `EDITION` |
| 中文标题 | `TITLE_ZH` |
| 英文短标题 | `TITLE_EN`（越短越好，2–3 个词；长标题会被自动缩字号） |
| 讲师 | 不单独设字段时写进 `WECHAT_DETAILS` 或 `INTRO` |
| 日期 / 起止时间 | `DATE` / `TIME` |
| 地点 | `LOCATION` |
| 形式、自带设备、名额 | `FEATURES`、`TOP_LINE` |
| 主办方全称 | `ORGANIZER`；是否显示文字用 `ORGANIZER_STYLE`（`logo-only` / `text` / `none`） |
| 联办单位 | `ORGANIZER_STYLE: "text"` + `ORGANIZER_LABEL` / `ORGANIZER` |
| 讲什么 / 做什么 / 带走什么 | `INTRO` + `STEP1~3_TITLE` / `STEP1~3_DESC` + `TAKEAWAY_TITLE` / `TAKEAWAY_COPY` |
| 工具与技术点 | `TOPICS`、`SCHEDULE`、`WECHAT_STEPS` |
| 报名时间 / 名额 / 方式 | `REGISTRATION`、`QR_CAPTION` |
| 费用说明 | `FOLLOW_UP` |
| 报名二维码 | `QR_IMAGE`（缺失就留占位，**不得伪造**） |
| 主题插画 | `ILLUSTRATION_FILE`（自己画则用内联 SVG，见 style-guide） |
| 主办/合作方 Logo | `ORGANIZER_LOGO` |
| 聊天/网页预览 | 交付时引用 `@2x` 文件；印刷、投影一律 `@2x` |

## 生成后自检

1. 产物里**不能出现**用户点名禁止的内容（把禁用词当搜索串逐一核对 PNG 以外的产物与微信文案）。
2. 日期、星期、时间、地点、名额、报名路径逐字对齐用户的原话。
3. 二维码：从成品 PNG 里裁出二维码区域重新解码，确认能扫出正确链接。
4. 视觉检查（标题不溢出、Logo 不变形、底部不裁切）：没有读图能力时，用可读图的模型复核，或明确告诉用户"我没法看图，请你过一眼"。
5. 用户没提供的项，逐条列在交付说明里，不把半成品说成完成。
