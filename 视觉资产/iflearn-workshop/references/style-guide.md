# IF.Learn 视觉规范

## 风格基准

横版参考 `examples/01-ai-coding.png`、`02-ai-hardware.png`、`03-3d-print.png`。三者共享浅灰背景、橙黑标题块、左对齐信息层级和右侧主题插画。易拉宝与横幅另参考 `01-ai-coding-rollup.png`、`01-ai-coding-banner.png`，不要直接套用横版构图。

## 色彩

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#EEEEEC` |
| 主橙色块 | `#FF4F0B` |
| 插画亮橙 | `#FF6038` |
| 日期与重点文字 | `#D74B18` |
| 主黑 | `#111110` |
| 次级正文 | `#555550` |
| 弱辅助文字 | `#777772` |
| 分割线 | `#C7C7C2` |
| 插画灰 | `#B7BAB7` |

功能色仅用于硬件、电线或界面细节，例如 `#3157D5`、`#F2B640`。不要增加渐变背景、玻璃拟态或无意义光效。

## 字体与 Logo

- 英文与数字：Inter Variable。
- 中文：思源黑体 Regular / Medium / Bold / Heavy。
- 使用本地 `@font-face`，正文启用 `font-size-adjust: from-font`，避免字体加载造成版式漂移。
- IF.Link 与 IF.Learn 使用官方 SVG。浅底使用 light 版本，黑底使用 dark 版本。
- IF.Learn 原始 PNG / SVG 四周带空白，排版统一使用 `iflearn-light-trimmed.svg`；IF.Link 同理使用 `iflink-light-trimmed.svg`，黑色页脚使用 `iflink-dark-trimmed.png`。裁切素材同时存于 `references/`。不要用带白边的原始文件参与对齐。
- 多个 Logo 保持视觉高度一致；合作方没有 Logo 时使用文字，不创造临时官方标识。

## 版式

### 横版海报

- 基准画布：1280×720；高清导出：2560×1440。
- 页面边距：54px；顶部品牌区：34px。
- 系列标识位于左上至中部，橙色英文标题块与黑色中文标题块上下相接。
- 主题插画位于右侧，底部保留时间、地点、报名二维码和课程收获。
- 英文标题应与橙色块体量匹配；长标题降低字号，不留下明显半空标题块。

### 易拉宝

- 基准画布：1600×4000，比例 2:5。
- 结构参照 AI Coding 原版：顶部品牌区；巨大的 IF.Learn 橙色块与 Workshop 黑色块；一句系列口号；右侧小插画；下方编号课程安排；黑色品牌页脚。
- 黑色页脚固定使用左侧白色 IF.Link、英文标语和社区说明，右侧微信公众号与小红书双二维码；不要改成单课程二维码或主办方页脚。
- 易拉宝是系列入口，不把单场课程标题做成比 IF.Learn Workshop 更强的主标题。
- 课程安排使用 3–4 个编号步骤，每步包含短标题和一句说明；时间地点集中在插画左侧。
- 不把横版简单拉伸为竖版，不让插画占据整段竖向空间。

### 横幅

- 基准画布：3000×500，比例 6:1。
- 结构参照 AI Coding 原版：IF.Learn Logo + Workshop 居中大字；其下为单场课程橙色标签；时间地点集中一行。
- 右侧保留主题插画，主办方以小号文字置于左下角，不另设大型左侧品牌栏。
- 不放中文黑色副标题块、课程步骤、详细收益或二维码，避免多层信息争抢注意力。

## 插画

- 优先使用内联 SVG，线宽、圆角和阴影保持一致。
- 推荐结构：课程工具 / 实物为主体，屏幕或成果为辅助，必要时用橙色虚线表达转换过程。
- 现有插画可直接复用：AI Coding 方块、ESP32 硬件、Blender + 3D 打印机、内容文稿 + Workshop。
- 新主题先提炼一个核心动作，例如“连接”“生成”“打印”“发布”，再绘制对应物件。

## 验收

- 查看实际导出的三张 PNG，而非只检查 HTML。
- 检查文字裁切、孤立单字换行、底部信息过挤、二维码静区和 Logo 清晰度。
- 二维码必须来自本次活动，不复用其他课程群码；无法确认时保留占位并披露。
- 时间使用 24 小时制，日期与星期由配置明确给出，不自行猜测。
