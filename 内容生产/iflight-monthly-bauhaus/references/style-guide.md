# 月榜赛包豪斯视觉规范

## 色彩与材质

模板变量定义在 `templates/monthly.html` 的 `:root`，修改视觉基线时统一调整，不在每期复制一套 CSS。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#f2f0e8` | 米白纸张底色 |
| `--white` | `#fffdf7` | 卡片与深色底反白文字 |
| `--ink` | `#151515` | 主文字、轮廓、阴影 |
| `--red` | `#e34b36` | 主奖、包裹、重点几何 |
| `--red-dark` | `#b93225` | 红色侧面与暗部 |
| `--blue` | `#2856c7` | 蓝色舞台、路径、第二入口 |
| `--blue-dark` | `#193d91` | 蓝色侧面与暗部 |
| `--yellow` | `#f0c946` | 爆破光、项目广场、提示 |
| `--yellow-light` | `#ffe382` | 黄色顶面与次级强调 |
| `--green` | `#b1fa63` | 招募、数据、关键行动 |
| `--muted` | `#6d6a64` | 辅助说明 |

红、蓝、黄各自的前面和顶面不能互相误覆盖；深色面板使用米白文字，不使用低对比灰字。

## 网格与几何

- 正文基准宽度为 **375 CSS px**，最终长图宽度为 **1080px**。
- 大板块用粗黑轮廓、平移硬阴影和明确留白建立层级，不靠多重嵌套框压缩正文。
- 折线路径连接内容，不代替正文容器。长文放在宽面板中，避免一两字一行。
- 项目卡在移动端单列展示；未提供图片时使用几何占位，不拿上期项目图补位。
- 领奖台正面、顶面、侧面共享边界，侧面不无故凸出，颜色不串位。

## 字体

标题与正文使用模板已有的 Arial、PingFang SC、Microsoft YaHei 等系统回退；英文编号使用 Courier New。需要指定思源黑体时，由当前任务确认字体资源，不隐式携带上一台电脑的字体路径。

SVG 文本同时保留字体属性与内联样式。品牌 Logo 优先使用包内路径，不重新描摹。

## 动效语言

- 传送带连续运送创意包裹，是固定开场，不随意替换为普通静态标题。
- 包裹下落、开盖、爆破和引子展开形成同一个 Out of Box 叙事。
- 折线与折叠面板把不同权益串起来；触发动画不能遮住正文。
- 领奖台把展示、反馈与更多机会组织成结束场景。
- HTML 保留 `?static=1` 与减少动效设置；导出 SVG 长图时暂停动画并选择完整可读时刻。

## 可替换与不可替换

**每期替换**：届次、标题、赛程、投票规则、奖项、推荐赛事、项目介绍与图片、社区数据、署名、链接。

**默认固定**：颜色、几何关系、网格、开场和结尾、卡片结构、Logo、无署名品牌 Banner、导出适配器。

若需要改变视觉语言或 Banner 版式，先判断是本期特例还是长期基线；不要把一次局部修订固化成所有期次的规则。

## 验收重点

1. 文字不被几何、折线或多重边框遮挡。
2. 项目图比例正确，示例项目不加载真实图片。
3. 期次、金额、日期与署名来自本期配置，不出现上一期残留。
4. 开头与结尾动效均有可读静态状态。
5. HTML 与 SVG 同位置对照，所有 SVG 文本实际可见。
6. 分段小于 30 KB，真实项目图使用本期图床链接。
