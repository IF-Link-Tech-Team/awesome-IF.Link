# WeChat Forwarding Copy

Use this format when the user wants the text sent alongside the infographic and Feishu card.

## Tone

- Warm, direct, slightly energetic.
- Short enough to sit above an image/card in WeChat.
- Human, not PR-like. Avoid “不是...而是...”, “赋能”, “沉淀成体系”, “持续追踪” unless the user asks.
- Use a few emojis for scanning, not decoration overload.

## Template

```text
今日份「IF.Link 社区雷达」来啦！

昨天 {date}「IF.Linker AI 交流群」{one-line-day-summary}：
🔍 {highlight 1}
🤖 {highlight 2}
🖼️ {highlight 3}
🌐 {highlight 4}
🚀 {highlight 5}

进群可联系值班管理员 @{admin}

完整雷达见 👉 {link placeholder}
```

## Rules

- Keep 4-6 highlights.
- Each highlight should be concrete: topic + what happened / what can be used.
- Prefer “模型鉴别：用特殊 token 观察模型入口是否稳定” over vague “模型讨论很多”.
- Mention projects by name when they are a community draw.
- Do not include every topic from the Feishu doc.
- If sending with an image and Feishu link card, the copy can be shorter than the infographic.

## Example

```text
今日份「IF.Link 社区雷达」来啦！

昨天 6/18「IF.Linker AI 交流群」首日，群聊内容丰富有深度：
🔍 模型鉴别：用特殊 token 观察模型入口是否稳定（GLM 5.2 / PoC）
🤖 多 Agent 编排：拆 milestone、加 reviewer 和 auditor，长任务才能收得回来
🖼️ 小模型识图：把物理卷子先转结构化文本，再交给强模型推理
🌐 校园网络：SEU-OpenWrt-Gateway 解决 portal 自动登录 + 多设备共享
🚀 同学项目：搭子 SEU、求职主理人 HR 都在持续推进

进群可联系值班管理员 @{admin}

完整雷达见 👉 {link}
```
